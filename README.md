## 关于科思律师事务所

广东科思律师事务所（KESI LAW FIRM）由陈焕律师、李琪瑶律师联合创立。科思于2026年在深圳前海设立，立足粤港澳大湾区、面向全球，服务新经济企业与成长型企业。品牌主张为“理解商业，解决问题，陪伴长期发展”。

科思关注人工智能、数据与数字经济，也围绕企业经营中的合同、交易、股权、治理及争议解决提供法律支持。服务强调理解技术和商业模式，将法律要求落实为合同文本、业务流程与具体行动。

## 主要业务与服务场景

### 1. 人工智能与大模型

AI项目合规规划、训练数据与开源协议审查、算法备案及大模型登记支持、产品上线审查、用户协议和隐私政策、全生命周期合规与相关争议。

### 2. 数据合规与资产化

数据合规制度建设、数据产品登记与上架辅导、交易合规评审、数据资产入表支持、公共数据与网络数据合规、个人信息保护影响评估及审计。

### 3. 跨境出海与国际业务

AI产品出海、数据跨境、目标市场规则研究、涉外合同、国际贸易与跨境项目协调。

### 4. 知识产权

AI生成内容权属与侵权风险、软件及技术成果保护、商标与著作权、商业秘密及相关争议。

### 5. 合同与常年法律顾问

SaaS、API、云服务、技术开发和数据供应合同，标准合同体系、日常咨询、谈判及重大交易支持。

### 6. 股权投融资与并购

股权架构、员工激励、法律尽职调查、投融资交易文件、并购交割与投后治理。

### 7. 企业治理与风险防范

公司治理与授权机制、内部管理制度、劳动用工、商业合作、经营风险识别与应对。

### 8. 争议解决与刑事业务

合同、股权、知识产权等民商事争议，诉讼仲裁、保全执行，企业刑事风险及刑民交叉问题。

### 9. 培训与能力建设

管理层与业务团队的AI、数据和经营风险培训，法律人AI工具应用、合规制度宣贯及工作坊。

## 代表实务经验

陈焕及团队的历年项目经验涵盖以下领域： [2025年度回顾](https://mp.weixin.qq.com/s/-1XJmTmQAn0VOcP51Y4SVg)

- **AI产品全生命周期合规**：AI陪伴数字人、AI玩具及医疗AI等项目的合规支持；智能调研分析AI的大模型登记；AI-API、AI情绪评估等项目的咨询或评审。
- **数据交易与个人信息保护**：数据产品上架辅导、公共数据产品评审、个人信息保护影响评估，以及智能终端未成年人个人信息保护审计等工作。
- **数据资产化**：参与数据产品登记挂牌、数据资产入表与运营合规工作；累计参与数据产品上架及合规评审100余项。
- **跨境与智能终端**：出海AI产品法律顾问、智能终端企业涉外合同审查及跨境经营风险支持。
- **企业顾问与争议解决**：AI及数字经济企业常年法律顾问、网络名誉权争议，以及生物制造、医药等行业合同争议。
