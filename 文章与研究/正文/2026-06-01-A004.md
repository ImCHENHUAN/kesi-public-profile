# 数据、算法等首次写入商业秘密范围｜商业秘密新规今日生效

2026年6月1日，国家市场监督管理总局发布的《商业秘密保护规定》（以下简称"新规"）正式施行，同日废止了1995年原国家工商行政管理局颁布的《关于禁止侵犯商业秘密行为的若干规定》（以下简称"旧规"）。这部时隔逾30年的全面修订，不仅在体量上从12条扩容至31条，更在保护范围、行为界定、执法程序、法律责任等维度实现了系统性升级。本文将聚焦新规的核心亮点，并与旧规进行逐维对比，为企业商业秘密保护实践提供参考。

“PART 01 新规五大亮点解读

亮点一：数据、算法、计算机程序、代码等首次被明确纳入商业秘密定义

商业秘密定义的细化，本次修订最引人注目的变化之一。旧规对技术信息的列举仅提及"设计、程序、产品配方、制作工艺、制作方法"等较为笼统的表述，在数字经济高速发展的当下已明显滞后。

新规第十二条明确将数据、算法、计算机程序、代码等写入技术信息的定义范畴：

"与技术有关的结构、原料、配方、材料、样品、样式、工艺、方法、数据、算法、计算机程序、代码等信息，属于第一款所称的技术信息。"

同时，经营信息中也明确列举了数据：

"与经营活动有关的创意、管理、销售、财务、计划、样本、客户信息、数据等信息，属于第一款所称的经营信息。"

该变化意味着：

•

算法模型（如推荐算法、合成算法、风控模型等）可以作为商业秘密获得保护；

•

源代码和目标代码除了依赖著作权保护，还可以通过商业秘密路径获得双重保护；

•

经营数据（如用户行为数据、交易数据、市场分析数据）只要满足"不为公众所知悉、具有商业价值、采取相应保密措施"三要件，也可构成商业秘密。

新规为AI企业、互联网平台、SaaS服务商等数据驱动型企业提供了更多的保护路径，但也必然为未来一定时间内的司法和行政执法留下了更多的讨论空间。

亮点二：保密措施要求全面升级，首次数字化场景覆盖

新规对"权利人采取相应保密措施"作出了大幅细化，从旧规简单列举的"订立保密协议、建立保密制度及其他合理保密措施"，扩展为八种具体情形，其中尤为突出的是对数字化办公场景的专门回应：

"针对远程办公、跨境协作等场景，采取权限分级、数据脱敏、操作日志留痕等技术保密措施"

同时还包括：

•

对计算机设备、网络设备、存储设备采取禁止或限制使用、访问、存储、复制等措施；

•

对涉密场所进行区分管理；

•

要求离职员工登记、返还、清除、销毁其接触的商业秘密及其载体。

在混合办公和跨境协作成为常态的背景下，企业仅凭一纸保密协议已不足以满足"采取相应保密措施"的法定要求，技术性保密措施的部署将成为合规刚需。

还有一点个人感受，从措辞上来看，各种“保密措施”多为数据合规律师常见的表述，未来与这种场景相关的争议解决案件，疑似利好数据合规律师。

亮点三：不正当手段类型细化，电子侵入行为被精准描述

旧规对不正当手段的表述极为概括——"盗窃、利诱、胁迫或者其他不正当手段"。新规则在保留这一框架的基础上，将实践中高发的侵权行为类型化：

•

数字化系统侵入：未经授权擅自进入权利人的数字化办公系统、服务器、邮箱、云盘、应用账户，或者通过设置恶意程序、漏洞攻击等技术手段获取商业秘密；

•

越权下载传输：未经授权或超出授权范围，擅自将商业秘密下载或传输至不受权利人控制的电子邮箱、云盘等网络存储空间或电子设备；

•

物理载体窃取：未经授权擅自接触、占有或复制包含商业秘密的文件、物品、材料、原料等载；

•

商业贿赂方式：通过提供财物或其他财产性利益、人身威胁等方式，贿赂、胁迫、欺骗权利人员工或前员工获取商业秘密。

不正当手段类型的细化，意味着"离职前批量下载公司代码到个人云盘"这类在实务中多发的行为，在新规下有明确的法律定性。

亮点四：首次明确不构成侵犯商业秘密的行为

新规第十五条首次以专条形式明确了不属于侵犯商业秘密的行为：

•

独立研发：独立发现或自行研发；

•

反向工程：对从公开渠道取得的产品进行拆卸、测绘、分析等获得有关技术信息（即合法反向工程）；

•

通用知识技能：前员工利用在工作中积累的通用知识、技能、行业经验开展工作；

•

公益举报：基于揭露违法犯罪行为、维护国家安全和社会公共利益等需要，依法向国家机关披露商业秘密。

该条既明确了合法反向工程的边界，也为人才流动中"通用知识技能"和"商业秘密"的区分提供了法律指引，避免商业秘密保护过度扩张而抑制创新和人才流动。

但可以预见的是，在未来的商业秘密、知识产权诉讼中，论证“通用知识技能”将是一块兵家必争的战略高地。

亮点五：处罚力度大幅提升，域外管辖条款首现

在法律责任层面，新规将罚款幅度从旧规的"一万元以上二十万元以下"大幅提升至"十万元以上一百万元以下"，情节严重的"一百万元以上五百万元以下"，起罚点和上限分别提高了10倍和25倍。

同时，新规第二十九条首次规定了域外适用条款，对跨境技术合作、国际人才流动中的商业秘密保护具有深远影响：

"在中华人民共和国境外实施侵犯商业秘密行为，扰乱境内市场竞争秩序，损害境内经营者合法权益的，依照反不正当竞争法以及有关法律的规定处理。"

“PART 02 新旧规定逐维对比表

| 对比维度 | 《关于禁止侵犯商业秘密行为的若干规定》（失效） | 《商业秘密保护规定》（2026年6月1日起施行） |
|---|---|---|
| 条文数量 | 12条 | 31条 |
| 商业秘密定义 | 不为公众所知悉、能为权利人带来经济利益、具有实用性并经权利人采取保密措施的技术信息和经营信息 | 不为公众所知悉、具有商业价值并经权利人采取相应保密措施的技术信息、经营信息等商业信息（第5条第1款） |
| 技术信息范围 | 设计、程序、产品配方、制作工艺、制作方法等 | 与技术有关的结构、原料、配方、材料、样品、样式、工艺、方法、数据、算法、计算机程序、代码等信息，属于第一款所称的技术信息（第5条第2款） |
| "价值性"要件 | "具有实用性（具有确定的可应用性）"+"能为权利人带来现实的或者潜在的经济利益或者竞争优势" | "具有商业价值"，强调现实或潜在价值，明确阶段性成果、失败实验数据也属于具有商业价值（第7条） |
| "秘密性"要件 | "不能从公开渠道直接获取" | 详细列举五种为公众所知悉的情形，并明确加工改进后形成的新信息可构成不为公众所知悉（第5条） |
| 保密措施 | 订立保密协议、建立保密制度及采取其他合理的保密措施 | 八种具体情形，涵盖保密协议、规章制度、场所管理、数字化技术措施、离职管理等方面（第9条） |
| 不正当手段 | 盗窃、利诱、胁迫或其他不正当手段 | 五类细化：物理载体窃取、商业贿赂、数字化系统侵入、越权下载传输、其他（第10条） |
| 教唆引诱帮助 | 未作专门规定 | 专条规定，列举怂恿指使、物质/职位诱导、提供便利条件等情形（第13条） |
| 合法抗辩事由 | 未明确规定 | 专条规定独立研发、反向工程、通用知识技能、揭露犯罪等合法行为（第15条） |
| 罚款幅度 | 1万元至20万元 | 10万元至100万元；情节严重100万元至500万元（第24条） |
| 情节严重的认定 | 未明确 | 列举直接损失数额较大、重大不利影响、危害国家/社会公共利益、二年内再犯等情形（第26条） |
| 停止侵害措施 | 返还图纸、软件等资料；销毁侵权产品 | 五项细化措施：停止使用、返还/销毁载体、销毁侵权产品/中间品、清除商业秘密、其他（第25条） |
| 举报与立案条件 | 提供商业秘密及侵权行为存在的有关证据 | 细化初步证据材料要求（形成过程/非公知性/商业价值/保密措施），明确立案三条件（第17、18、19条） |
| 鉴定与专业意见 | 未规定 | 允许委托鉴定机构对非公知性和实质相同性进行鉴定，允许有专门知识的人出具专业意见（第22条） |
| 域外适用 | 未规定 | 明确规定境外侵权行为扰乱境内市场秩序的可适用本规定第（29条） |
| 管辖 | 县级以上工商行政管理机关 | 技术秘密案件一般由设区的市级以上市场监督管理局管辖，经批准可由有能力的县级管辖（第3条） |

“PART 03 给企业的合规建议

面对新规的全面升级，企业应当从以下方面审视和提升商业秘密保护体系：

1.

梳理商业秘密资产清单：特别关注算法、代码、数据集、失败的实验数据等新增明确保护对象，建立分级分类的商业秘密台账。

2.

升级技术性保密措施：根据新规，仅靠保密协议难以满足保密要求，建议企业部署权限分级、操作日志留痕、数据脱敏、设备管控等技术手段，确保保密措施与新规要求匹配。

3.

完善离职管理制度：建立离职员工商业秘密登记、返还、清除、销毁的标准化流程，保留书面记录以备举证。

4.

留存研发过程记录：对于阶段性成果和失败实验数据，建议建立完整的研发日志，以证明商业信息的形成过程、非公知性和商业价值。
