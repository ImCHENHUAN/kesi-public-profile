# 法律AI公司在版权侵权诉讼中败诉 | 美国首案

本周二，美国特拉华州地方法院对“汤森路透”诉法律AI公司Ross Intelligence版权侵权诉讼作出部分简易判决”，汤森路透赢得美国首例AI训练版权诉讼，本案主要情况如下：

原被告基本情况：

原告：Thomson Reuters（汤森路透）拥有大型法律研究平台Westlaw，Westlaw平台提供案例法、州法和联邦法规、法律期刊等内容，以及对司法意见的编辑性内容和注释（headnotes）和用于分类的Key Number System。

被告：Ross Intelligence（以下简称Ross）是一家法律研究搜索引擎公司，致力于通过人工智能技术向法律人员提供法律研究服务的AI工具。

但是Ross自2020年深陷于汤森路透的版权诉讼以来，花费大量资金来应对诉讼，无法继续筹得资金已经于2021年1月停止运营了......

（ROSS官网在2020年12月发布的公告）

案件背景：

- Ross需要大量关于法律问题和答案的数据来训练其AI工具，但汤森路透拒绝了Ross提出的授权使用Westlaw内容的请求。

- Ross随后与LegalEase达成协议，获取了大约两万多份备忘录（Bulk Memos），而这些批量备忘录是律师根据Westlaw的headnotes整理的法律问题和答案。

- Ross利用这些Bulk Memos训练其AI工具。

原告汤森路透的诉讼主张：

- Westlaw平台的headnotes和Key Number System具有独创性，应当受版权的保护。
- Ross从第三方获取的Bulk Memos训练数据，依赖于Westlaw的headnotes，构成间接复制。Ross将这些Bulk Memos作为训练数据，开发法律AI工具。汤森路透认为Ross的行为侵犯了其对Westlaw headnotes和Key Number System的版权。

法院裁判：

1.headnotes和Key Number System具有独创性：

法官确认汤森路透对Westlaw的headnotesKey Number System享有版权。法官认为即使headnotes的部分内容引用司法意见，但编辑的提炼过程构成独创性表达。对于Key Number System，法院认为尽管部分分类由计算机程序生成且基于常见的法律主题，但Key Number System的特定组织结构仍满足独创性的要求。

2.版权侵权成立：

- 被告实施了复制行为：通过比对Bulk Memo、headnotes和原始司法意见，法官认定被告复制了原告2000多条的headnotes。被告训练数据的来源方LegalEase明确指示律师参考Westlaw生成问题，且Ross使用了约80%的Bulk Memos训练其法律AI工具，构成侵权证据。

- 实质性相似：法官认为，Bulk Memo与headnotes的相似性远超原始司法意见，普通用户（如律师等）可感知二者的实质性相似。

3.被告合理使用等抗辩不成立：

被告围绕合理使用的四大因素提出抗辩：

- 目的与性质：Ross产品的商业用途与Westlaw不构成直接竞争。
- 作品性质：headnotes虽具独创性，但创造性低于文学作品。
- 使用数量比例：Ross未公开headnotes，没有将headnotes直接提供给终端用户，仅用于内部训练。
- 市场影响：Ross的AI工具可能替代Westlaw，损害汤森路透的现有市场和潜在数据许可市场。

法官最终没有采纳被告构成合理使用的抗辩理由，对于被告提出的其他抗辩，也均予以驳回。

同时，法官在本案裁决中也强调独创性和转换性在合理使用判断中的重要性：

- 针对“转换性使用”：Ross的使用并非“转换性使用”，因为Ross没有“进一步的目的或具备不同的特征”，而是为了开发与Westlaw进行竞争的法律研究工具。

- 针对独创性：法官认为虽然Westlaw的内容具有独创性，但其独创性程度有限，因此对合理使用的判断影响较小。

本案作为美国首例AI版权诉讼，对于训练数据是否构成合理使用等问题进行了探讨，或许将对美国后续的AI训练版权问题，以及创作者与AI企业产生深远影响。

对判决书感兴趣的读者，可后台回复“汤森路透”获取判决原文。

不知道国内的法律AI公司有没有瑟瑟发抖，被告通过第三方购买训练数据，也没能逃过原告的版权侵权起诉，法院不仅认可了原告享有版权，还驳回了被告的合理使用抗辩。

训练数据来源等法律问题，已经逐渐成为AI公司不可忽视的问题了。
